# Prova de Programação em C

Resoluções das 10 questões, em arquivos separados para abrir no Dev-C++.

| Questão | Conteúdo |
| --- | --- |
| 1 | Calculadora: soma, subtração, multiplicação e divisão |
| 2 | Estrutura `for` de 1 a 10 |
| 3 | Estrutura `while` de 1 a 5 |
| 4 | Estrutura `do while` para validar senha |
| 5 | Saída do `for`: 1, 2, 3, 4 e 5 (um por linha) |
| 6 | Saída do `if`: Maior que 3 |
| 7 | Calculadora com menu e `switch case` |
| 8 | Tabuada usando `for` |
| 9 | Soma de 1 até 5 usando `while`: 15 |
| 10 | Números pares entre 1 e 20 usando `for` e `%` |

## Como executar

Abra um arquivo `.c` por vez no Dev-C++ e use **Compilar e Executar** (geralmente F11). Cada questão possui sua própria função `main()`.

**Observação da questão 5:** o código apresentado no enunciado original contém um sinal `+` isolado depois do laço. Com esse sinal, ele não compila. O arquivo `questao_05.c` contém a versão corrigida, que exibe 1 a 5.
